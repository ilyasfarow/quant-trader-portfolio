# Quant Trading & Portfolio Analysis Platform

A Python-based quantitative trading project exploring systematic trading strategies, financial data analysis, backtesting, portfolio performance, and machine learning.

The project is designed as a practical learning platform for experimenting with quantitative finance concepts and developing a stronger understanding of how data-driven trading strategies are designed, tested, and evaluated.

---

## Overview

This project currently contains two main approaches to analysing financial markets:

1. **Rule-based quantitative strategy** — identifies periods of below-average market volatility and takes a position during those periods.
2. **Machine learning model** — uses technical indicators to predict whether the next trading day's return will be positive or negative.

The project also includes a terminal-based interface for running backtests, ML predictions, and comparing multiple stocks.

## Trading Strategy

The current rule-based strategy uses market volatility as its primary signal.

### Strategy logic

The strategy calculates the 20-day rolling standard deviation of daily returns.

When current volatility is below the historical average volatility:

**→ Take a position**

Otherwise:

**→ Stay in cash**

Positions are shifted by one trading day before calculating strategy returns. This prevents the strategy from using information from the same trading day to make a trading decision, helping avoid look-ahead bias.

---

## Machine Learning Model

The project also includes a Random Forest classification model to predict the direction of the next trading day's return.

### Target

The target variable is:

- `1` → next day's return is positive
- `0` → next day's return is zero or negative

### Current features

The model currently uses:

- 10-day Simple Moving Average
- 50-day Simple Moving Average

The data is divided into training and testing periods, with the model trained on historical observations before 2022 and evaluated on observations from 2022 onwards.

The model also generates a prediction for the next trading day based on the latest available features.

> The machine learning component is experimental and is intended for research and learning rather than live trading.

## Performance Metrics

The backtesting component evaluates both the market and the strategy using several metrics.

### Annual Return

Measures the average annualised return generated by the market or strategy.

### Annual Volatility

Measures the annualised variability of returns.

### Sharpe Ratio

Measures risk-adjusted performance by comparing returns against volatility.

### Maximum Drawdown

Measures the largest decline from a previous peak in the portfolio's value.

These metrics allow different stocks and strategies to be compared on both return and risk.

## Multi-Ticker Analysis

The terminal interface supports comparing multiple stocks in a single run.

Example:

```text
AAPL, MSFT, NVDA, AMZN
```

Each ticker is processed independently and its performance metrics are returned for comparison.

This allows the project to move beyond analysing a single asset and towards systematic comparison of different securities.

## Current Limitations

This project is still under development.

Some important limitations of the current implementation include:

- The strategy does not currently model transaction costs.
- Slippage is not currently included.
- The current strategy uses a relatively simple volatility signal.
- Machine learning validation could be improved using time-series-specific validation techniques.
- The current ML model uses a limited feature set.
- Portfolio-level position sizing and risk management are not yet implemented.
- The current annual return calculation could be improved using compound annual growth rate (CAGR).
- The current backtesting framework could be expanded to support more sophisticated portfolio construction.

These limitations are intentional areas for future development.
