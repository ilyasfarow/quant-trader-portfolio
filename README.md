# Quant Trading Strategy Project

## Strategy
This project tests a simple rule-based strategy:

Invest only when:
- Market volatility is low
- Otherwise stay in cash

## Method
- Data: NVDA historical prices (Yahoo Finance)
- Volatility: 20-day rolling standard deviation
- Backtesting with no look-ahead bias

## Metrics
- Annual return
- Volatility
- Sharpe ratio
- Drawdown

## Goal
To understand how volatility regimes affect market performance.
